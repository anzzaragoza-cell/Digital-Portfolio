# Activity 1 – Presentation Design Principles

## Overview

This activity focuses on the application of presentation design principles.

The purpose of the activity is to understand how the arrangement of visual elements can improve the clarity, organization, and effectiveness of a presentation.

---

## Design Principles Applied

### 1. Visual Hierarchy

Visual hierarchy was used to make important information more noticeable. Headings, titles, and supporting information were given different levels of emphasis.

### 2. Alignment

Alignment was used to organize elements and create a cleaner overall composition.

### 3. Contrast

Contrast was used to distinguish important elements and make information easier to identify.

### 4. Balance

Visual elements were distributed throughout the composition to create a balanced appearance.

### 5. Consistency

Consistent visual elements were used throughout the design to create a unified presentation.

---

## Development Process

The activity began with identifying the main information that needed to be presented. The visual elements were then arranged using presentation design principles.

Different elements were organized according to their importance, while spacing, typography, and visual emphasis were considered to improve readability.

---

## Reflection

This activity helped me understand that presentation design is not only about making a presentation visually attractive. Good design also helps an audience understand information more quickly and allows ideas to be communicated more effectively.
