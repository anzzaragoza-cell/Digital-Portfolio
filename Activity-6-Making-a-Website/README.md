# Activity 6 – Making a Website

## About This Activity
In this activity, I made a website with the help of AI, using an old 2000s retro look. The website showcases my previous AI bots for Source engine games, using retro-style design elements to match the era of the games.

## Files
All output files for this activity are in this folder.

## What Have I Learned?
- I learned how a design style, like the retro look of the 2000s, can set the mood of a website and make it fit its topic.
- I learned how to describe the look and layout I wanted to an AI so it could help build the website.
- **Challenge:** It was hard to get the retro look right, and some links and images did not show up at first. I solved it by adjusting my instructions to the AI and checking the file names and paths until everything displayed correctly.
- In the future, I can use these skills to build a website for my other projects or a professional portfolio, and I will keep the design consistent and easy to use.
