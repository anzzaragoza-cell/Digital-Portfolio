## What Have I Learned?
- I learned how to build and organize slides in Google Slides using layouts, themes and visuals.
- I learned how to export a presentation as a PDF so it can be shared and opened on any device.
- **Challenge:** Some of my slides had different layouts and looked inconsistent. I solved it by using one theme and the same layout style across all slides.
- In the future, I can use Google Slides for case presentations and for sharing work with a group.
