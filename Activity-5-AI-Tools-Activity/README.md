# Activity 5 – AI Tools Activity

## About This Activity
In this activity, I used Claude AI and compared two prompts for creating bots for an old Source engine multiplayer game. I wrote one vague prompt and one more specific prompt that matched my needs. The specific prompt helped Claude create a better framework for the AI bots to follow.

## Files
All output files for this activity are in this folder.

## What Have I Learned?
- The quality of an AI's output depends heavily on the quality of the prompt. A vague prompt gave general results, while a specific prompt gave a clearer and more useful framework.
- A good prompt states the goal, the context, and the behavior I want, so the AI does not have to guess what I need.
- **Challenge:** My first vague prompt gave results that did not match what I wanted for the bots. I solved it by rewriting the prompt with specific details about how the bots should behave and comparing the two results.
- In the future, I will write detailed prompts from the start, test and improve them step by step, and check the AI's output before using it.
