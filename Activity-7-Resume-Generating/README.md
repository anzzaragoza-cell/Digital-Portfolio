# Activity 7 – Resume Generating

## About This Activity
This activity was about generating a professional one-page resume with the help of AI tools. I gave my education, clinical experiences, competencies, training and awards, and asked for a modern, clean resume for an entry-level hospital nursing job.

## Files
All output files for this activity are in this folder.

## What Have I Learned?
- I learned how to organize my academic background, clinical experiences and skills in a one-page format that is easy for a recruiter to scan.
- I learned that a clear prompt with complete details gives a better result, and that I still have to check dates, titles and spelling myself.
- **Challenge:** A resume contains an address, phone number and references, so I had to decide how much personal information to make public. I solved it by keeping the public version limited to what an employer needs.
- In the future, I can update this resume with my PRC license once I pass the board exam and adapt it for different hospitals.
